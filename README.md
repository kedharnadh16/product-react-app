# Product Management System

A full-stack **Product Management System** developed using **React.js, Spring Boot, and MySQL**.

This project demonstrates the development of a web application where the **React frontend** communicates with a **Spring Boot REST API** to manage product information. It is being developed as a practical full-stack project to understand frontend development, backend APIs, database integration, and client-server communication.

## 🔄 Application Flow

```text
React Frontend
      ↓
   REST API
      ↓
Spring Boot Backend
      ↓
     MySQL
```

The frontend sends HTTP requests to the Spring Boot backend, which processes the request and interacts with the MySQL database.
